## Candidate decision

NWS raw grid forecasts are the most promising independent no-key US fallback. Official documentation lists temperature, wind speed/gust, quantitative precipitation, snowfall, visibility and structured weather, with explicit valid-time intervals and units. Use /points discovery then cache/coalesce by office/grid coordinate; do not send one unconstrained request per sample. Official source: https://weather-gov.github.io/api/gridpoints and https://www.weather.gov/documentation/services-web-api.

This is not a drop-in mapping: visibility may be null, rain/snow totals may span several hours, and NDFD weather categories are not WMO codes. Dividing a multi-hour precipitation accumulation into an invented hourly intensity, treating null visibility as clear, or inventing code0 would violate the existing risk semantics. Before implementation acceptance, validate actual representative grids, explicit interval/unit normalization, conservative partial data handling and documented category mapping. Retain Open-Meteo for other countries; never label US fallback as global coverage. Official APIs still have limits and no SLA. This is a viable bounded next investigation, not a verified fallback implementation.
